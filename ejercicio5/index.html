6️⃣ Tarea 6: Punto Final — Lista de Verificación Directa en Motor (Unity)

A continuación debes realizar y verificar cada uno de los siguientes pasos dentro de tu editor de motor (Unity) para dar por entregado el laboratorio práctico:

1. Crear GameObject "NetworkManager" en la escena principal:

Añade el componente NetworkManager. Configura Protocol ProtocolType en UnityTransport.

2. Crear Prefab de Jugador con Componentes de Red:

En el Prefab del avatar asigna los componentes NetworkObject, NetworkTransform y el script PlayerNetworkMovement.cs.

3. Enlazar Prefab al NetworkManager:

Arrastra el Prefab del jugador a la casilla PlayerPrefab en el Inspector de NetworkManager para que el servidor lo spawnee automáticamente al conectar.

4. Implementar Interfaz Canvas UI para Conexión:

Crea dos botones UI ("Iniciar Host" e "Iniciar Cliente") vinculados a los métodos StartHost() y StartClient() del script NetworkLobbyManager.cs.

5. Prueba Final con Build Ejecutable y Editor:

Genera una Build Standalone (File -> Build Settings). Abre la Build como Host y el Editor como Cliente (o usando Multiplayer Play Mode). Verifica que no haya advertencias en la consola.

1. Crear Escena Principal (main.tscn) con Nodos de Red:

Agrega un nodo Node3D principal y adjunta el script Autoload/Gestor network_manager.gd.

2. Configurar Escena de Jugador (player.tscn) con Sincronizador:

Añade un nodo CharacterBody3D con MultiplayerSynchronizer y MultiplayerSpawner. Configura las propiedades sincronizadas (position y rotation).

3. Asignar Autoridad en el Script del Jugador:

Implementa set_multiplayer_authority(name.to_int()) en _enter_tree() y filtra las entradas de teclado con is_multiplayer_authority().

4. Crear Botones de Control en CanvasLayer:

Agrega botones en pantalla para invocar create_host_server() y join_as_client("127.0.0.1").

5. Probar con Múltiples Instancias Simultáneas:

Ve a Debug -> Run Multiple Instances -> 2 Instances. Presiona F5 y verifica la sincronización fluida del movimiento entre ventanas.
